# Product Context

Обновлено: 2026-11-25.

## Проблема (подтверждено владельцем)

Владелец ведёт тренировки в Excel. Основные боли:

- вести журнал тренировок;
- помнить упражнения, веса и подходы;
- понимать, когда повышать вес;
- рассчитывать вес на текущую тренировку с учётом прошлых;
- составлять программу;
- засекать время перерывов;
- видеть календарь тренировок;
- отслеживать прогресс: историю весов, подходов и объёма.

Итог: данные и расчёты разрознены, ручной ввод и формулы отнимают время, нет автоматической
подсказки по весу, таймера, календаря и наглядного прогресса.

## Пользователи

- Основной пользователь MVP — владелец; продукт проектируется под его рабочий процесс.
- Сегментация не влияет на логику тренировок: сценарии одинаковы для новичка и опытного.
- Внешние интервью недоступны (других пользователей нет). Валидация — собственное
  использование и сравнение с Excel. Риск: решение может оказаться слишком персональным.

## Текущие альтернативы

- Excel (подтверждено): гибко, но ручной ввод, формулы, нет таймера и автоматической прогрессии.
- FitNotes: полностью офлайн, бесплатно, без аккаунта; прогрессия ручная, нет конструктора
  программ и учёта реальных сеток весов.
- Strong: шаблоны, таймер, калькулятор блинов; часть функций по подписке, прогрессии по сетке
  тренажёра нет.
- Hevy: соцфункции, таймер; облако и аккаунт, офлайн частичный.
- JEFIT: слабый офлайн, подписка.
- Вывод: ниша — офлайн-приложение без аккаунта с реальными сетками весов, весом снаряда
  (Смит, каретка) и автоматической прогрессией по сетке.

## Гипотеза ценности

Если приложение само помнит историю, подставляет прошлые веса, считает следующий вес по сетке
тренажёра и ведёт таймер отдыха, владелец перестанет вести Excel-таблицу и будет быстрее
принимать решение о весе на тренировке.

## Метрика успеха MVP

- Полностью заменить Excel на 4 неделях тренировок.
- Видеть календарь тренировок и прогресс без ручной сборки графиков.
- Ввод одного подхода — меньше 15 секунд.
- Подсказка следующего веса принимается без ручной правки в большинстве подходов.
- Нет потери данных при переустановке или смене устройства (экспорт/импорт).

## UX-цели (из структуры модели)

- Быстрый ввод факта: вес, повторы, RIR, отметка разминки.
- Подсказки по технике и отдыху во время тренировки.
- Прогрессия по сетке весов тренажёра, а не по абстрактным процентам.
- Учёт веса снаряда (гриф Смита, каретка) через `base_weight_kg`.
- Работа офлайн.
