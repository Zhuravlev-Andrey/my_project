## Границы

- In scope (подтверждено владельцем 2026-11-25): локальные данные, Room/SQLite, полная
  работа без интернета.
- Out of scope (подтверждено): серверная часть, аккаунты, синхронизация, сетевые функции,
  аналитика и телеметрия. Остальные границы продукта — TODO на этапе 1.
- Платформа: Android-смартфоны, minSdk 24, targetSdk 37.

## Ключевые требования (проверяемые)

- Вес — в килограммах (`Double`), для гантелей — одной гантели.
- Время — `Long` (мс с 01.01.1970 UTC), без конвертеров Room.
- Инвентарь: тренажёры, сетки весов, упражнения, мышечные группы.
- Шаблоны: программы → тренировки → упражнения → схемы подходов.
- Факт: тренировка (`session`) и подходы (`session_set`); вес в факте — снимок, не ссылка на сетку.
- Прогрессия: правило на упражнение (порог повторов, число подходов, шаг по сетке).
- Работа без интернета.
